# Guía de Instalación
## Sistema de Gestión de Incidencias

Esta guía explica cómo instalar y ejecutar localmente el Sistema de Gestión de Incidencias.

---

## 1. Tecnologías utilizadas

El sistema fue desarrollado con:

- Java 17
- Spring Boot
- PostgreSQL 16
- HTML
- CSS
- JavaScript
- Maven Wrapper
- JWT para autenticación
- BCrypt para almacenamiento seguro de contraseñas

---

## 2. Requisitos previos

Antes de ejecutar el sistema se debe tener instalado:

### Java 17

Verificar con:

java -version
